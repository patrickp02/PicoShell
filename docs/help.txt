PicoShell Commands

General:
  help, h
      Show this help message.

  clear
      Clear the terminal.

  about
      Show PicoShell version and platform information.

  version
      Show the PicoShell version.

  uptime
      Show time since PicoShell started.

  reboot
      Hard reset the Pico.

  reset
      Soft reset MicroPython.

Wi-Fi / Networking:
  wifi
      Scan/connect to Wi-Fi, or disconnect from the current network.

  wifi setup
      Save a new Wi-Fi SSID/password to config.txt.
      Useful after connecting to the PicoShell fallback access point.
      Run reboot afterward to try the saved network.

  ifconfig
      Show station and active access-point interface configuration.

  scan
      Scan nearby Wi-Fi networks.

  ping <host>
      TCP-connect latency/reachability test using port 80.

  curl <url>
      Fetch and display a URL.

  clone <url> [name]
      Download a file from an HTTPS URL.
      Raw GitHub URLs are supported.

  pmap <host> [start] [end]
      Scan a TCP port range.
      Default range: 1-1024.

  telnet launch
  telnet stop
      Start or stop the Telnet server.
      Telnet auto-starts after Wi-Fi by default for headless use.
      Set TELNET_AUTO=0 in config.txt to disable auto-start.

Fallback AP:
  If the saved Wi-Fi network is missing or cannot be joined within about
  13 seconds, PicoShell can start its own WPA2 setup network.

  Default SSID:
      PicoShell-XXXXXX

  Default password:
      picoshell

  Default IP:
      192.168.4.1

  Connect a phone/laptop to that SSID, then Telnet to 192.168.4.1 and run:
      wifi setup
      reboot

  AP_FALLBACK=0 disables this behavior.
  AP_PASSWORD=<8-63 chars> changes the fallback AP password.
  TELNET_AUTO must be enabled for Telnet to auto-start on the fallback AP.

Filesystem:
  pwd
      Show current directory.

  ls [path]
      List files and directories.

  cd <dir>
      Change current directory.

  mkdir <dir>
      Create a directory.

  rmdir <dir>
      Remove an empty directory.

  rm <file>
      Remove a file.

  read <file>
      Print a text file.

  cp <source> <destination>
      Copy a file.

  mv <source> <destination>
      Move or rename a file.

  touch <file>
      Create a file if it does not exist.

  tree [path] [max_depth]
      Recursively show the directory tree.
      Default path: .
      Default max depth: 8

  write <file> <text>
      Overwrite a file with text.

  append <file> <text>
      Append one line of text to a file.

Scripts:
  run <file.py>
      Execute a Python script from storage.

System:
  sysinfo
      Show MicroPython system information.

  dspace
      Show flash storage usage.

  ram
      Show RAM usage.

  freemem
      Show RAM, run garbage collection, then show RAM again.

  clock
      Show CPU clock speed.

  setclock <MHz>
      Set CPU clock speed.
      Allowed range: greater than 40 MHz and less than 260 MHz.

  temp
      Show CPU temperature using the current PicoShell implementation.

  blink [times] [delay_seconds]
      Blink the onboard LED.

Hardware:
  gpio read <pin>
      Read a GPIO pin.

  gpio write <pin> <0|1>
      Drive a GPIO pin low or high.

  gpio mode <pin> <in|out|pullup|pulldown>
      Configure a GPIO mode.

  i2c scan <bus> <sda_pin> <scl_pin> [freq_hz]
      Scan an I2C bus for devices.
      Example:
        i2c scan 0 0 1 400000

Updater:
  update check
      Compare the local version against GitHub version.txt.

  update install
      Transactionally download a newer PicoShell version and reboot.

      Updates include main.py, utils.py, boot.py, telnet/utelnetserver.py,
      docs/help.txt and version.txt. Updates are downloaded to temporary files
      first and installed only after every download succeeds.

Development:
  exit
      Leave PicoShell and return to the raw MicroPython REPL.

  Ctrl+C
      Stop PicoShell and return to the raw MicroPython REPL so Thonny can
      regain filesystem access.
